# DNS Manager: Утилита настройки DNS

Простой и удобный скрипт для быстрого переключения DNS-серверов в ОС Windows. Скрипт объединяет в себе логику Batch и PowerShell, предоставляя консольный графический интерфейс для управления сетевыми адаптерами, настройки DoH (DNS over HTTPS) и очистки кэша.

## Основные возможности

* **Xbox DNS (RU / РЕЗЕРВ)**: Смена DNS для обхода региональных ограничений на консолях Xbox.
* **Comss DNS (Нейросети)**: Настройка Smart DNS (Control D) для беспрепятственного доступа к ИИ-сервисам (ChatGPT, Claude, Gemini).
* **Cloudflare DNS (Global)**: Переключение на быстрые и безопасные глобальные серверы Cloudflare (1.1.1.1).
* **Обходной лист**: Редактирование локального списка обхода DNS (файла `hosts`) прямо из скрипта с автоматическим созданием шаблона и сбросом кэша после закрытия Блокнота.
* **Сброс настроек**: Возврат всех сетевых адаптеров в автоматический режим (получение DNS от вашего провайдера) и отключение DoH.
* **Очистка кэша**: Быстрый сброс локального DNS-кэша Windows без изменения самих серверов.
* **Оптимизация быстродействия (v1.3)**: Использование .NET-интерфейсов для мгновенного определения статуса DNS и пинга (вместо медленных командлетов PowerShell). Кэширование статуса делает навигацию в меню моментальной.
* **Новый плиточный UI 3x4**: Двухцветная плиточная сетка с разграничением на DNS-профили и системные утилиты с автоматической подгонкой размеров окна консоли (95x32).
* **Механизм обновлений**: Встроенная функция проверки и скачивания новых версий скрипта (OTA-обновления).

## Требования

* **ОС**: Windows 10 или Windows 11.
* **Права доступа**: Права администратора (скрипт запрашивает их автоматически при запуске).

## Использование

1. Скачайте файл `dns.bat` на ваш компьютер.
2. Запустите файл двойным кликом.
3. При появлении окна контроля учетных записей (UAC) разрешите внесение изменений.
4. В открывшемся меню используйте **Стрелки** на клавиатуре для навигации между плитками.
5. Нажмите **Enter** для применения выбранной настройки.

## Настройка системы обновлений

Чтобы встроенный механизм обновлений работал корректно, вам необходимо указать ссылку на ваш сервер или репозиторий, где хранится актуальная версия файла.

Откройте `dns.bat` в любом текстовом редакторе и найдите строку:

```powershell
$UpdateUrl = "https://raw.githubusercontent.com/ВАШ_ПОЛЬЗОВАТЕЛЬ/ВАШ_РЕПОЗИТОРИЙ/main/dns.bat"

```

Замените URL на вашу прямую ссылку (RAW) на скрипт. Скрипт будет скачивать этот файл, извлекать из него значение `$AppVersion` и, если оно выше текущего, автоматически заменять свой исходный код новым.
